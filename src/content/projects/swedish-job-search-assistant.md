problem: "A tool for reviewing Swedish job advertisements faster, with every judgement traceable. It finds current ads, explains how each one relates to the user's supplied profile evidence, and helps prepare an application. It is a decision aid. It does not predict whether someone would be hired."
methodTitle: "Implemented features"
method:
  - title: "API ingestion"
    text: "Fetches ads from the public JobSearch API in bounded queries per search track, with retry and backoff, into a local SQLite database. Repeated refreshes never duplicate an ad."
  - title: "Revision and deadline tracking"
    text: "Keeps a revision history for changed ads and tracks deadlines. Removed and past-deadline ads leave the shortlist but stay in history, and a failed refresh keeps the old jobs and shows a stale-data warning."
  - title: "Source-quoted requirements"
    text: "Extracts language, degree, experience, skill and work-model requirements with transparent rules. Each one keeps its quote and character offsets from the ad."
  - title: "Assessment against profile evidence"
    text: "Compares requirements with a profile the user writes. Every match cites an evidence entry and its basis, and missing evidence is shown as unknown, never as lacking. Jobs fall into Prioritise, Worth reviewing, Stretch, Significant barrier or Excluded, and excluded jobs stay recoverable with the quoted reason."
  - title: "Persistent corrections"
    text: "A requirement can be corrected to mandatory, preferred, unspecified, not required or ignored, with a note. Corrections and labels on jobs are stored in the database."
  - title: "Saved applications"
    text: "Jobs can be saved and tracked through considering, preparing, applied, interview and closed, with notes and dates."
  - title: "Preparation briefs"
    text: "A brief for each ad, built only from the profile file: which evidence to emphasise against each quoted requirement, relevant projects, gaps and what to clarify. Academic and managed work is labelled as such."
  - title: "Ranking-evaluation harness"
    text: "A labelling queue (half top-ranked, half random) and an evaluation page that compares the rule-based order with text similarity and, optionally, local multilingual embeddings, using the user's own labels."
limitsTitle: "Status and limits"
limits:
  - "This is a local MVP under active development, not a hosted service. It has no accounts, notifications or multi-user support, and refreshes happen only while the app is running. It is not an application agent and does not submit applications."
  - "Ranking quality is unvalidated. The evaluation reports precision among labelled jobs, not full-list precision, and there is no frozen held-out set yet. Unlabelled jobs are unknown, never negative. Nothing here shows that it improves hiring outcomes."
  - "The semantic ranker is optional and unvalidated. It is an extra sort option, and the rule-based order stays the default."
  - "Requirement extraction is rule-based and recognises about 40 skill terms. Its precision and recall have not been measured."
  - "Prioritise means the ad's asked skills have evidence in the profile. It is a suggestion to review, not proof of suitability."
  - "Only the JobSearch source is implemented, and the app does not claim complete coverage of Swedish vacancies. Ad text is stored as received and can contain personal data, so the database stays private. The repository contains only synthetic demo data."
